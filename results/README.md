# Results

The saved output of every query in this project, produced by `run_all.sh` on the full Olist dataset.

| File | Contents |
|---|---|
| `02_data_quality.txt` | Row counts, missing dates, orders without items, duplicate reviews, payment mismatches |
| `01_sales_trends.txt` | Monthly revenue and growth, YTD and moving average, YoY growth, shopping times, best and worst days |
| `02_customer_analysis.txt` | Repeat purchase rate, RFM segments, cohort retention, time to 2nd order, revenue by state |
| `03_delivery_performance.txt` | Delivery KPIs, late % by state, late delivery vs reviews, same-state vs cross-state, monthly trend |
| `04_seller_analysis.txt` | Top sellers, Pareto check, revenue by seller decile, risky sellers, seller vs customer location |
| `05_payments.txt` | Payment mix, credit card instalments, multi-method orders, cancellations by payment type |
| `06_product_analysis.txt` | Top categories, fastest-growing categories, worst-rated categories, freight vs weight, photos vs sales |

The findings drawn from these outputs are in [insights.md](../insights.md).
